¿Por qué se realiza esta dinámica? Porque antes de aprender cómo elegir o crear imágenes para una publicación, es importante observar cómo una imagen puede llamar la atención, transmitir una sensación y ayudar a comunicar un mensaje.

¿Qué es una imagen?

Una imagen es una representación visual que permite mostrar personas, productos, objetos, lugares o situaciones.

En una publicación, la imagen ayuda a llamar la atención, comunicar una idea y transmitir sensaciones de forma rápida.

¿Qué es un personaje?

Un personaje es una persona representada visualmente dentro de una imagen. Puede utilizarse para mostrar quién podría usar, necesitar o beneficiarse de un producto o servicio.

Para que funcione en una publicación, el personaje debe tener relación con el producto, el consumidor y el mensaje que queremos comunicar.

¿Qué es la composición?

La composición es la forma de organizar y relacionar los diferentes elementos dentro de una imagen para comunicar una idea de manera clara y atractiva.

En una imagen publicitaria podemos combinar elementos como el personaje, producto y escenario para representar una situación relacionada con el consumo o uso del producto o servicio.

Una buena composición busca que los elementos tengan relación entre sí y que la persona pueda comprender fácilmente qué está ocurriendo en la imagen.

¿Qué elementos puede tener una publicidad?

Una publicidad combina diferentes elementos visuales y de información para llamar la atención, presentar una propuesta y facilitar que la persona comprenda qué se ofrece.

Dependiendo del objetivo de la publicación, podemos utilizar los siguientes elementos:

Personaje: representa a una persona que utiliza, consume o se relaciona con el producto o servicio.

Producto o servicio: debe permitir comprender claramente qué se está ofreciendo.

Lugar o escenario: muestra un ambiente relacionado con el uso, consumo o adquisición del producto o servicio.

Título: es un mensaje corto que busca llamar la atención y comunicar la idea principal.

Beneficio: explica qué obtiene o qué puede resultar útil para el consumidor.

Precio: informa cuánto cuesta cuando este dato es importante para la decisión de compra.

Promoción: comunica una oferta o condición especial cuando realmente existe.

Identidad visual: utiliza los colores, fuentes y elementos visuales definidos para la empresa.

Logotipo: permite identificar visualmente a la empresa o marca.

Llamado a la acción: indica qué debe hacer la persona después de observar la publicidad, por ejemplo: escribir, consultar, reservar, solicitar información o comprar.

¿Todos los elementos deben aparecer siempre?

No. Los elementos se seleccionan según el producto, el consumidor y el objetivo de la publicidad.

Una publicidad debe evitar colocar información solamente para llenar espacio. Cada elemento debe tener una función dentro del mensaje.

¿Qué es la tonalidad de voz en una locución publicitaria?

La tonalidad de voz es la manera en que el locutor utiliza su voz para darle una determinada intención al mensaje publicitario.

El locutor no solamente debe leer un texto. Debe interpretarlo para transmitir la sensación adecuada según el producto, servicio, público y objetivo del anuncio.

Por ejemplo, un mismo texto puede sonar alegre, tranquilo, serio, enérgico o urgente dependiendo de cómo utilicemos la voz.

¿Qué elementos utiliza un locutor para cambiar su voz?

Tono: permite que la voz se perciba más grave o más aguda.

Ritmo: determina la velocidad con la que se comunica el mensaje. Puede ser más rápido o más pausado.

Intensidad: permite utilizar la voz con mayor o menor fuerza según lo que se quiere destacar.

Pausas: son pequeños silencios que permiten separar ideas, facilitar la comprensión y destacar información.

Énfasis: consiste en destacar determinadas palabras para dirigir la atención hacia la información más importante.

Intención: es lo que queremos transmitir mediante la voz: informar, emocionar, convencer, generar interés o motivar una acción.

¿Qué tonalidades podemos utilizar en publicidad?

Alegre: transmite una sensación positiva y dinámica.

Enérgica: utiliza mayor intensidad y ritmo para captar rápidamente la atención.

Entusiasta: demuestra emoción e interés por aquello que se está ofreciendo.

Cercana: busca hablar al consumidor de una manera natural y personal.

Seria: utiliza una interpretación más controlada y directa.

Formal: utiliza una expresión cuidada y apropiada para comunicaciones que requieren mayor formalidad.

Tranquila: utiliza un ritmo más pausado y una intensidad moderada.

Persuasiva: busca generar interés y conducir al consumidor hacia una decisión o acción.

Urgente: utiliza ritmo, intensidad y énfasis para comunicar que existe una acción que debe realizarse rápidamente.

¿Cómo elige un locutor la tonalidad adecuada?

Antes de grabar, el locutor debe comprender qué producto o servicio anuncia, a quién se dirige y qué quiere conseguir con el mensaje.

Después adapta el tono, ritmo, intensidad, pausas y énfasis para conseguir la intención deseada.

Por eso, una locución publicitaria no consiste simplemente en leer. Consiste en interpretar el mensaje con la voz.
